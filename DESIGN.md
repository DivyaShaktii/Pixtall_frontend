# Design System

## Theme
Minimalist and elegant, high contrast, output-driven.

## Colors
- Accent: Vibrant Tangerine (#ff4d2e)
- Neutral: Ink
- Neutral: Paper

## Typography
- Display Serif: Hero headlines and emphasis.
- Body Sans (Inter): Standard UI text.
- Mono Label: Technical metadata and tags.

## Shadows
- shadow-xs: 0 1px 2px rgba(14,14,16,0.04) (Subtle lift)
- shadow-lg: 0 24px 64px rgba(14,14,16,0.14) (Deep structural elevation)

## Components
- Generate Button: Solid background, subtle shadow on hover.
